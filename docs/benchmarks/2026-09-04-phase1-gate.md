## Why this is not a pass — the measurement is under-powered

The fixture carries **11 planted facts**. One fact flipping moves the score by
**9 percentage points**. A threshold at 85% cannot be resolved by an instrument
whose smallest increment is 9 points; the observed 73–100% spread is what that
looks like.

[15](../15-testing-and-evaluation.md) § 3 specifies suite 1 as **20 facts across
100 turns, probed at turns 30/60/100 and in a fresh session**. What was actually
built is 11 facts across 39 turns with probes appended at the end. That is a
smoke test, not suite 1.

**Reporting 91% as a pass would be reporting the median of a noisy instrument as
though it were a measurement.** The correct next step is to build the specified
fixture and re-run, not to tune extraction until a small sample happens to land
above the line.

### The concentrated failure

The Ashford Inquiry stores **1 memory from 6 turns**, every run. Its script
plants facts inside questions the player asks (*"I ask Hobbes about the
decanter"*) rather than statements the player makes. The extraction gate's
signals — commissive verbs, irreversible events, preferences — do not fire on
interrogatives.

This is a genuine gap worth fixing regardless of the fixture size: in a mystery,
what the player *asks* is often the durable fact.

## The other ten measurements

Everything below was stable across all seven runs.

### 2–3. Calls per turn

| | |
|---|---|
| Dialogue calls | 0.95 / turn |
| Extraction calls | 0.64 / turn |
| **Total** | **1.64–1.69 / turn** |
| Gate skipped | **36% of turns** |

ADR-016's deterministic gate is doing real work: **more than a third of turns
spend no inference at all** on extraction. That is the single largest cost
saving in the system, and it costs nothing to run.

### 4–6. Tokens per turn

| | |
|---|---|
| Input | 1,044 |
| Output | 421 |
| **Reasoning** | **369–407** |
| **Total** | **~1,430** |

**Reasoning tokens are 95–97% of content output** — they roughly double what a
generation costs. Any capacity estimate that ignores them is wrong by about a
factor of two, which is exactly what the earlier ~16.4K figure did.

### 7. Groq 8K ceiling

| | |
|---|---|
| Largest observed request | 1,325 tokens |
| Headroom | 6,675 tokens |
| Size rejections | **0** |

The compact profile is far more comfortable than expected — it uses about a
sixth of the ceiling. The four canonical worlds are small, so this will grow with
real worlds carrying more rules, relationships and history, but ADR-020's
constraint is not currently binding.

### 8. Latency

| | |
|---|---|
| Dialogue p50 | 631–690 ms |
| Dialogue p95 | 1,077–1,178 ms |

Comfortably inside the < 2 s fast-tier target ([08](../08-ai-router.md) § 2), and
well inside the < 6 s p95 turn target.

### 9. Failures

Rose across consecutive runs — **3% → 5% → 7% → 12% → 15%** — as the credential
pool's per-minute token budget depleted. Every failure was `RATE_LIMITED`, and
the pool routed around them correctly. Zero malformed outputs after the
name-resolution fix.

This is the credential pool behaving exactly as designed under sustained load,
and it is also a reminder that back-to-back eval runs are not representative of
user traffic.

### 10–11. Measured capacity

| | |
|---|---|
| Calls per turn | 1.69 |
| Tokens per turn | ~1,430 |
| Request pool | 32,000 req/day (8 credentials × 4 models × 1,000) |
| Token pool | 256,000 tok/min |
| **Turns/day** | **~18,900** — request-bound |
| Sustained | 13.5 turns/min |
| Burst | ~175 turns/min |
| DAU at 20 turns each | **~975** |

**Requests bind before tokens**, and by a wide margin. The token pool could
support ~175 turns/minute; the request pool allows ~13.5 sustained. Reducing
calls per turn is therefore worth far more than reducing context size — which
inverts the assumption behind ADR-012.

The earlier ~16.4K estimate was close by coincidence: it ignored reasoning tokens
(which would have lowered it) and also ignored that requests bind before tokens
(which raises it). Two errors in opposite directions.

## Actions

- [ ] **P1-T14** — build suite 1 as specified: 20 facts, 100 turns, probes at
      30/60/100 and in a fresh session. Until then the gate is unmeasurable.
- [ ] Extend the extraction gate to fire on **interrogatives** — what a player
      asks is often the durable fact, especially in mystery worlds.
- [ ] Re-run the gate on the proper fixture, 5 runs, report the median.
- [ ] Reconsider ADR-012's premise: context size is a *quality* lever here, not
      the economic one. Calls per turn is the economic lever.
